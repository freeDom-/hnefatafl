# 0.13.0 - Adjustable resumption and faithful agent evaluations

Training can resume with reviewed optimizer changes. Gameplay and position
estimates share agent settings, completed games cannot restart, and remote worker
panels have consistent desktop/mobile spacing.

### Resume with optimizer changes

- Prefill learning rate, weight decay and momentum from the checkpoint's effective
  optimizer values, including older checkpoints with missing or stale metadata.
- Edit learning rate and weight decay for any supported optimizer. Edit momentum
  for SGD; Adam/AdamW retain their saved moments and show why momentum is disabled.
- Apply overrides after restoring optimizer state on both local and remote
  workers. Preserve accumulated buffers, weights, replay, random state and learning
  history. Unchanged settings retain their checkpoint values.
- Continue into a new job and output directory without changing the source.
  Network architecture and optimizer type stay fixed. SGD momentum is also
  configurable in the advanced new-training form and loadable from model settings.
- Provide English/German labels, explanations and validation.

### Evaluate and play with the selected agent

- Resolve profile defaults and explicit overrides consistently for direct search
  callers, including configured alpha-beta depth.
- Use backed-up neural search results for new winning-chance reports. Previously,
  model-backed search could find a winning move while the report still displayed
  only the network's raw current-position value.
- Display completed/requested alpha-beta depth and explain when the configured
  time limit stopped deeper search. Keep the time budget authoritative.
- Load the model's validated saved network depth. Network architecture and search
  depth/budget are separate settings.
- Preserve existing immutable replay reports and their original value-source
  labels. New searched reports use `neural_search`.

### Game and workshop fixes

- Hide Restart for finished games, including when undo/seek shows an earlier
  position. Reject completed-game restart requests through the API without
  creating another game or changing statistics. Unfinished games can still restart.
- Add the missing remote-worker panel padding and normalize card text gaps,
  including narrow screens and German controls.

### Validation

**369 backend cases**, **101 frontend unit tests** and **30 real-API browser
checks** pass. Four duplicate mobile worker checks remain intentionally skipped.
Ruff/Prettier, mypy, TypeScript and the production build pass.

Regression coverage includes actual optimizer buffer restoration, local and real
HTTP remote resumption with changed settings, independent agent depths for moves
and estimates, exact saved network architecture, discovered terminal wins and
completed-game restart rejection during replay. Browser flows edit all three SGD
settings and verify the retained checkpoint values. Desktop/mobile worker layouts
were inspected for spacing and overflow.

Exact suite results are recorded in
[VALIDATION.md](https://github.com/freeDom-/hnefatafl/blob/v0.13.0/docs/VALIDATION.md).

### Update and compatibility

Back up the complete data directory, stop the server, then update dependencies
and the browser build:

```sh
make install
make build
bash scripts/start.sh
```

Storage remains at **schema 6**; no database or checkpoint migration is required.
Older SGD checkpoints use their recorded momentum, defaulting to 0.9 where the
setting was not recorded. Use the same release on server and remote workers for
the new momentum setting. Previously recorded position estimates are preserved.

Winning chances remain uncalibrated agent estimates of expected score, with draws
worth half a point. Time-limited search may finish below the requested depth.
CPU workflow checks do not establish stronger models or GPU/cloud throughput.
