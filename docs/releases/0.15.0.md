# 0.15.0 - Background analytics and faithful game playback

Games remain interactive while agents analyze the board. Playing AIs now retain
estimates from their actual move searches, and an in-game Analytics panel provides
progressive move advice in both live games and history replay.

### Analytics and move advice

- Reuse the moving AI's search diagnostics instead of searching once for winning
  chances and again for its move. Save estimates, effective settings and seeds
  with the searched position for later replay.
- Evaluate other playing agents in background threads. Human input and AI move
  requests proceed independently; two AIs can retain separate opinions.
- Move advisor settings from New game into **Analytics**, below the move history.
  Select None (the default), a custom advisor, Shield bearer, Seer, Jarl or a
  compatible model. Maximum search time defaults to 5 seconds.
- Publish improved hints and estimates as alpha-beta depths or MCTS checkpoints
  finish. Advisor changes supersede old results, including delayed responses.
- Add **Show winning chances**. Hiding estimates keeps move advice available and
  suppresses advisor probability publication. Internal scores remain necessary
  to search for a move.
- Retain per-game settings and reports across reloads. Explicit replay-advisor
  opinions are stored separately from original playing-agent evidence.

### Game controls and fixed opponents

- Hide Resume AI and Next move for completed games, including earlier replay
  positions, and prevent automatic AI playback there.
- Close dialogs when the pointer is pressed outside their bounds. Dragging from
  inside a dialog and releasing outside keeps it open.
- Make Shield bearer a fixed 1-second opponent and Jarl a fixed depth-5,
  2-second opponent. Seer uses 5,000 iterations,
  temperature 0, exploration 1.4 and 2 seconds. Apply these presets in new games
  and tournaments; Custom opponents retain editable search settings.
- Keep captured kings visible in finished ordinary and tournament boards without
  changing the authoritative engine state, legal moves or outcomes.
- Preserve current Analytics settings when restarting an unfinished game, while
  assigning the restarted game a new seed. Recover safely from rejected settings
  saves and obsolete browser responses.
- Provide English and German labels for the new controls.

### Update and compatibility

Stop the server and back up the complete data directory before updating:

```sh
make install
make build
bash scripts/start.sh
```

Schema **7** adds per-game analytics preferences and revisioned advisor reports.
Migration is additive; older servers reject the new schema, so rollback requires
a consistent pre-upgrade backup. Game identities, historical configurations and
checkpoint formats are preserved.

Search budgets may expire before the requested depth or simulation count is
complete. Reports distinguish configured and completed depth. Estimates represent
expected score with draws worth half a point; they are not calibrated match-win
probabilities or evidence of model strength. CPU/browser behavior is verified;
GPU hardware and physical mobile browsers remain outside this milestone's checks.
