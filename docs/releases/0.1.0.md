# 0.1.0 — Architecture and development foundation

The project now has a reproducible Python development environment and documented
component boundaries for browser play, deterministic rules, AI and independent training.

### Added

- Python package with FastAPI, SQLite-oriented service architecture and optional
  PyTorch/Optuna training dependencies.
- Hash-locked dependency resolution with official CPU PyTorch wheels.
- Architecture decision record, acceptance checklist, development commands and CI.
- Release sequence that records delivered behavior and concrete validation evidence.

### Validation

- `uv sync --frozen --all-extras`: dependency installation and repeat run succeeded.
- `make foundation`: FastAPI and Optuna imports plus PyTorch tensor autograd succeeded.

### Getting started

Run `uv sync --frozen --all-extras` followed by `make foundation` with Python 3.11+.

### Limitations

This version establishes the development foundation. Game engine, browser gameplay,
search opponents and the training application are not delivered in this milestone.
No CUDA hardware validation or model-strength claim is made.
