# 0.2.0 — Three deterministic tafl rulesets

Applications, search opponents and training can now use one independently testable
engine for Tablut, Brandubh and Copenhagen, with immutable state and deterministic replay.

### Added

- Source-specific initial layouts, legal rook movement, captures and terminal states.
- Market Tablut: defenders start, unrestricted squares, sandwich king capture and
  escape to any edge, following the exact linked leaflet.
- Brandubh: 7×7 corner escape, restricted but passable throne, non-hostile center
  and ordinary king capture, following the linked leaflet.
- Copenhagen: 11×11 play, strong king, shieldwalls, encirclement, structural exit-fort
  recognition and defender loss on the documented repetition threshold.
- JSON state/move serialization, validated replay and in-depth rules documentation.

### Validation

- **61 engine tests passed**, including variant-specific royal captures, special
  squares, simultaneous captures, shieldwalls, encirclement, forts, repeated positions,
  invalid inputs and deterministic replay.
- Engine/test lint passed. Locked installation and the foundation autograd check passed.

### Usage

```python
from hnefatafl.engine import new_game, legal_moves, apply_move
state = new_game("tablut")
state = apply_move(state, legal_moves(state)[0])
print(state.to_dict())
```

Install with `uv sync --frozen --all-extras`; run
`.venv/bin/python -m pytest tests/test_engine.py`.

### Interpretations and limitations

- The linked Copenhagen primary page returned HTTP 455. The rules document identifies
  recovered transcriptions and their differences. This profile permits completing a
  shieldwall with the final backing piece, following the modern illustrated text;
  the older transcription's flank-only interpretation is explicitly distinguished.
  Independent verification against the primary page remains pending.
- Three occurrences of board plus side to move define the finite repetition threshold.
- No graphical gameplay or trained-model strength is claimed by this engine release.
